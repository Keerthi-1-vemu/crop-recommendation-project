# Crop Recommendation Project

This project recommends the best crop based on soil type, rainfall and temperature using Python.

## Author
Keerthi

## How to Run
1. Make sure `crops.csv` and `crop.py` are in same folder
2. Open terminal and run:python crop.py
3. Enter soil type, rainfall, temperature

## Example
Enter soil type: black
Enter rainfall: high
Enter temperature: hot
Recommended crop: COTTON
## Technologies Used
- Python
- CSV File Handling
